# Using the frame

## Tap menu

Tap anywhere on the slideshow:

- **Brightness** slider
- **Previous / Next** photo
- **Wi‑Fi**: Android's Wi‑Fi settings (to change network)
- **Frame settings**: see below
- **Android**: Android's own settings
- **Restart** / **Turn off** (asks first)
- **Close** (or wait 20 s)

The frame has no Android navigation bar. To get back from Android's settings, **hold two fingers on the screen for
2 seconds**, anywhere. The slideshow comes back.

On a video, tap **▶** to play it (always muted: the frame has no speaker). Tap again to stop.

## Frame settings

| Section | Options |
|---|---|
| Photo albums | add/remove shared album links, how often to re-read them, status, *Refresh now* |
| Slideshow | time per photo, shuffle, zoom effect, **fill the screen** (crop edges a little), **portrait photos side by side**, fade speed, include videos |
| On screen | date taken, camera (off, camera, camera with focal length and f-stop, or camera and full lens), clock, 24‑hour clock, weather on/off, weather location (search by town), °C/°F |
| Night mode | screen and backlight fully off between two times; a tap wakes it for 5 minutes |
| Remote settings | allow editing these settings from a phone/computer on the same Wi‑Fi (`http://<frame-ip>:8080/settings.html`). Restart, Turn off and screen controls still only work on the frame itself. |

Settings apply immediately, with no restart.

Set the **weather location** once after installing. The default is empty, so no weather shows until you pick a town.
